# 🌸 Ева — Календарь женского цикла

Уютное, приватное и красивое веб-приложение для отслеживания менструального цикла, созданное специально для мобильных устройств (в частности, iPhone в режиме PWA) с надежным облачным хранением в **Google Firebase** и возможностью публикации на **GitHub Pages**.

---

## ✨ Возможности приложения

- **💌 Послание дня (комплимент, предсказание и совет по заботе)**:
  - При каждом открытии приложение встречает нежным и вдохновляющим комплиментом, позитивным предсказанием на день и подсказкой по уходу за собой.
  - Кнопка «Ещё» с праздничной анимацией лепестков/конфетти позволяет вытянуть новую карту дня в любой момент.
- **⭕ Главный экран и фазы цикла**:
  - Круговой индикатор текущего дня цикла.
  - Определение текущей фазы: *Менструация*, *Фолликулярная фаза*, *День овуляции / Окно фертильности*, *Лютеиновая фаза (ПМС)*.
  - Обратный отсчет до следующих месячных или счетчик задержки.
  - Вероятность наступления беременности (низкая / средняя / высокая / пик овуляции).
  - Быстрая кнопка «Отметить месячные» / «Завершить месячные».
- **📅 Интерактивный календарь**:
  - Месячный обзор с цветовыми индикаторами:
    - 🔴 Дни месячных (насыщенный коралловый цвет).
    - 🌸 Прогноз следующих месячных (пунктирный контур).
    - 💜 День овуляции (лавандовый оттенок со звёздочкой).
    - 🌿 Окно фертильности (нежно-мятный цвет).
    - 🟡 Точка заметок и симптомов.
  - Нажатие на любой день открывает карточку подробной записи.
- **📝 Детальный трекинг дня**:
  - Интенсивность выделений: *Нет, Капли (мажущие), Легкие, Средние, Обильные*.
  - Симптомы: *Спазмы, Головная боль, Чувствительность груди, Вздутие, Усталость, Боль в пояснице, Высыпания, Тяга к сладкому, Тошнота, Бессонница*.
  - Настроение: *Радостное, Спокойное, Романтичное, Энергичное, Ранимое, Раздраженное, Тревожное, Грустное*.
  - Сексуальная активность: *Без защиты, С защитой, Высокое либидо, Не было*.
  - Текстовые заметки на любой день.
- **📊 История и статистика**:
  - Средняя длина цикла и средняя длительность месячных, рассчитанные на основе реальной истории.
  - Список всех прошедших циклов с возможностью редактирования и удаления.
  - Ручное добавление прошедших циклов.
- **🔒 Безопасность и надежность**:
  - Авторизация через **Google в 1 клик** (Firebase Auth).
  - Данные хранятся в облаке **Google Cloud Firestore** — при поломке, утере или смене телефона данные никогда не пропадут.
  - **100% приватность**: строгие правила `firestore.rules` разрешают доступ к данным **только владельцу учетной записи** (`request.auth.uid == userId`).
  - **Резервная копия**: кнопка «Скачать копию (.json)» для моментального сохранения всей базы в файл и возможность восстановления в один клик.
- **📱 Оптимизация для iPhone (PWA)**:
  - Поддержка Dynamic Island, чёлки и домашней полоски iOS (`env(safe-area-inset-*)`).
  - Установка на домашний экран Safari как отдельное нативное приложение без адресной строки.

## 🚀 Быстрый старт локально

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```
2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

## 🛠️ Пошаговый гайд по Firebase (Бесплатный план)

Для того чтобы приложение надежно хранило данные в облаке Google:

### Шаг 1: Создание проекта
1. Перейдите в [Firebase Console](https://console.firebase.google.com/) и войдите под своим Google-аккаунтом.
2. Нажмите **«Add project»** (Создать проект).
3. Введите название, например `eva-calendar`, и нажмите **Continue**.
4. Google Analytics можно отключить (снять галочку) и нажать **Create project**.

### Шаг 2: Включение входа через Google
1. В левом боковом меню перейдите в **Build** → **Authentication** → нажмите **Get started**.
2. Во вкладке **Sign-in method** выберите **Google**.
3. Переведите переключатель в положение **Enable**.
4. Укажите свой email в поле «Project support email» и нажмите **Save**.

### Шаг 3: Создание базы данных Cloud Firestore
1. В меню слева перейдите в **Build** → **Firestore Database** → нажмите **Create database**.
2. Выберите регион (например, `europe-west3` или `us-central1`).
3. Выберите режим **Start in test mode** или **production** (правила мы сейчас заменим) и нажмите **Create**.

### Шаг 4: Настройка строгой защиты (Rules)
В открывшейся базе Firestore перейдите во вкладку **Rules** (Правила), удалите всё содержимое и вставьте следующий код:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Доступ к данным имеет ТОЛЬКО владелец учетной записи (ваша жена)
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
Нажмите **Publish** (Опубликовать). Теперь никто, кроме авторизованного пользователя, не сможет прочитать или изменить её данные.

### Шаг 5: Получение ключей приложения
1. Нажмите на значок шестерёнки вверху слева ⚙️ → **Project settings**.
2. Прокрутите вниз до раздела **Your apps** и нажмите на круглую иконку веба `</>` (**Web**).
3. Введите имя приложения (например, `Eva Web`) и нажмите **Register app**.
4. Скопируйте объект конфигурации `firebaseConfig`. Вы можете:
   - Либо создать файл `.env` на основе `.env.example` и вставить значения туда.
   - Либо просто открыть приложение на телефоне, зайти в **Настройки** → **Ключи API** и вставить скопированный текст прямо туда!

### Шаг 6: Добавление домена GitHub Pages в Firebase
Чтобы Google разрешил авторизацию с вашего сайта на GitHub Pages:
1. В Firebase Console откройте **Build** → **Authentication** → вкладка **Settings** (Настройки).
2. Выберите **Authorized domains** (Авторизованные домены).
3. Нажмите **Add domain** и введите ваш домен GitHub Pages (например, `username.github.io`).

## 🌐 Выгрузка на GitHub Pages

### Вариант 1 (Автоматический через GitHub Actions — Рекомендуемый):
В репозитории уже настроен файл `.github/workflows/deploy.yml`. 
1. Создайте новый репозиторий на GitHub (например, `calendar`).
2. Привяжите локальный проект и отправьте код:
   ```bash
   git add .
   git commit -m "Initial commit of Eva Cycle Calendar"
   git remote add origin https://github.com/ВАШ_ЛОГИН/calendar.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках вашего репозитория на GitHub перейдите в **Settings** → **Pages** → в поле **Source** выберите **GitHub Actions**.
4. Всё! GitHub автоматически соберет и опубликует сайт по адресу: `https://ВАШ_ЛОГИН.github.io/calendar/`.

### Вариант 2 (Через команду deploy):
1. В `package.json` добавьте поле `"homepage": "https://ВАШ_ЛОГИН.github.io/calendar"`.
2. Запустите:
   ```bash
   npm run deploy
   ```

## 📱 Установка на iPhone жены (как нативное приложение)

1. Откройте ссылку на сайт (например, `https://ВАШ_ЛОГИН.github.io/calendar/`) в браузере **Safari** на iPhone.
2. Внизу экрана нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Прокрутите меню вниз и выберите **«На экран „Домой“»** (Add to Home Screen).
4. Нажмите **«Добавить»** в верхнем правом углу.
5. На рабочем столе появится красивая иконка с цветком лотоса. При запуске приложение откроется на весь экран без адресной строки Safari, как настоящее нативное iOS-приложение.
6. Нажмите кнопку входа и войдите через Google один раз. Сессия сохранится!
